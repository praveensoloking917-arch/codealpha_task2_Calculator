# Simple Calculator

A basic calculator built using **HTML, CSS, and JavaScript**. This project performs standard arithmetic operations with a clean and responsive user interface.

## 🚀 Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Percentage (%)
- Decimal calculations
- Clear screen (C)
- Delete last character (⌫)
- Real-time display updates
- Responsive design for mobile and desktop
- Keyboard support

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
